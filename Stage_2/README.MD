### Scope consistency

The revised charter uses the approved [Stage 3 technical decisions](../Stage_3/Report.MD): React, Express, PostgreSQL, REST polling, USER/ADMIN, public/private auctions, verified bank sandbox commitment, transactional bidding and fixed-time closure. Anti-sniping, WebSockets, Redis and real financial settlement are **not** part of the current MVP. See the *Scope Alignment Addendum* at the end of the report for the explicit decision history.
