# Enforce bid acceptance rules (BE-04)

## Scope

Review the rules that decide whether the bid endpoint accepts an offer. DB-09 covers the same transaction from the perspective of row locks and the final stored price.

## API Contract

| Route or surface | Access and input | Expected success or coverage |
| --- | --- | --- |
| `POST /api/v1/auctions/:id/bids` | Signed-in `USER`. Send a valid auction UUID and body with `amount` and a UUID `requestId`. | `201` with `data.bidId`, `data.amount` and `data.currentPrice` after commit. |

## Implementation

### 1. Check that the request can reach the auction

Validate the amount and identifier, then begin a transaction and lock the auction row. The seller cannot bid in their own auction. Private auctions return the same not-found result when an access grant is missing. [app.js 1346–1382](https://github.com/Abeerr0/mezyad/blob/bbaa86986727558124a3b9ab6de39e203549106b/backend/src/app.js#L1346-L1382)

### 2. Check request identity and the configured hold

A prior request ID is rejected. When `REQUIRE_BANK_COMMITMENT` is true, the handler checks the stored commitment, amount ceiling and live test-provider authorization, including timing. No commitment check runs in this handler when the flag is off. [app.js 1383–1496](https://github.com/Abeerr0/mezyad/blob/bbaa86986727558124a3b9ab6de39e203549106b/backend/src/app.js#L1383-L1496)

### 3. Read the current minimum and write once

Use the database clock after acquiring the lock. The first offer must reach the starting price. Later offers must reach the current price plus the minimum increment. The transaction inserts the bid and updates the price before returning `201`. The unique request constraint covers a concurrent duplicate that reaches the insert. [app.js 1497–1546](https://github.com/Abeerr0/mezyad/blob/bbaa86986727558124a3b9ab6de39e203549106b/backend/src/app.js#L1497-L1546) · [001_schema.sql 60–66](https://github.com/Abeerr0/mezyad/blob/bbaa86986727558124a3b9ab6de39e203549106b/database/migrations/001_schema.sql#L60-L66) · [DB-09 — atomic price updates](https://github.com/Abeerr0/mezyad/blob/bbaa86986727558124a3b9ab6de39e203549106b/Stage_4/Abeer-Task-Reports/DB-09.md)
