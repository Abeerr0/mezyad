# Build My Auctions and Bid History (FE-17)

**Status** Implemented

## Scope

My Auctions groups records a signed-in user owns or participated in. Bid History is a separate per-auction view for reviewing accepted offers.

## Implementation

### 1. Load and enrich personal auctions

The market hook loads account records from the authenticated endpoint. The page then requests details for each entry. An individual detail failure keeps that entry with a fallback message, while a list failure shows an error for the view. The all filter retains those fallback rows. [useMarket.js 335–350](https://github.com/Abeerr0/mezyad/blob/206b127eeb10af66ac115684d2531439a1405766/frontend/src/features/auctions/hooks/useMarket.js#L335-L350) · [MyAuctions.jsx 27–70](https://github.com/Abeerr0/mezyad/blob/206b127eeb10af66ac115684d2531439a1405766/frontend/src/features/auctions/pages/MyAuctions/MyAuctions.jsx#L27-L70) · [MyAuctions.jsx 100–114](https://github.com/Abeerr0/mezyad/blob/206b127eeb10af66ac115684d2531439a1405766/frontend/src/features/auctions/pages/MyAuctions/MyAuctions.jsx#L100-L114)

### 2. Show participation and outcomes

Cards distinguish ownership from participation and show bid count and the user's highest amount when available. Closed items with loaded details link to Result. Other entries open Details with the same auction ID. [MyAuctions.jsx 119–167](https://github.com/Abeerr0/mezyad/blob/206b127eeb10af66ac115684d2531439a1405766/frontend/src/features/auctions/pages/MyAuctions/MyAuctions.jsx#L119-L167)

### 3. Paginate an auction's history

The history page turns on bid loading for the current auction and stores its offset locally. The previous button stops at the first page. Next is enabled when the current page contains 20 rows. Changes request the new offset through the market hook. [BidHistory.jsx 15–20](https://github.com/Abeerr0/mezyad/blob/206b127eeb10af66ac115684d2531439a1405766/frontend/src/features/auctions/pages/BidHistory/BidHistory.jsx#L15-L20) · [BidHistory.jsx 29–68](https://github.com/Abeerr0/mezyad/blob/206b127eeb10af66ac115684d2531439a1405766/frontend/src/features/auctions/pages/BidHistory/BidHistory.jsx#L29-L68) · [useMarket.js 211–223](https://github.com/Abeerr0/mezyad/blob/206b127eeb10af66ac115684d2531439a1405766/frontend/src/features/auctions/hooks/useMarket.js#L211-L223)

## UI/UX

| Page or component | Frontend file | What the user sees and does |
| --- | --- | --- |
| My Auctions | `MyAuctions.jsx`, `MyAuctions.css` | Filter by auction state and see whether each entry is owned, participated in or linked to the account. |
| Participation cards | `MyAuctions.jsx` | See the number of bids and highest personal bid when available. Open Details or Result according to the auction state. |
| Bid history | `BidHistory.jsx` | Review accepted offers for the current auction and move between history pages. |
| Market data | `useMarket.js` | Load account auctions and retrieve bid rows in pages of 20. |
