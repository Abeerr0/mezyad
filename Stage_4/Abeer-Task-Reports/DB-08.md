# Verify seller and admin listing queries (DB-08)

## Scope

Check owner scope, the admin review filter, current review fields and image arrays using recorded test data.

## Schema & Constraints

| Table or relationship | Key columns | Rule |
| --- | --- | --- |
| Seller list | `items.seller_id` | Query uses the caller’s ID. A composite seller/status index is defined. |
| Admin queue | `items.status` | An admin with a valid status gets matching items across sellers. |
| Images | `item_images.item_id` | One batch read grouped by item. An item without images gets an empty array. |
| Review data | `status`, `review_reason`, `reviewed_by`, `reviewed_at` | Returned item rows retain their review metadata. |

## Implementation

### 1. Read the right listing set

The items route validates the filter. Filtered admin queries use the status; other requests use the seller ID, including an unfiltered admin request. The account route always uses the caller’s ID. [listings.js 255–280](https://github.com/Abeerr0/mezyad/blob/e4fc24953b75d37f2f905df454fe82ecd1e65103/backend/src/listings.js#L255-L280) · [app.js 1576–1590](https://github.com/Abeerr0/mezyad/blob/e4fc24953b75d37f2f905df454fe82ecd1e65103/backend/src/app.js#L1576-L1590) · [001_schema.sql 73–77](https://github.com/Abeerr0/mezyad/blob/e4fc24953b75d37f2f905df454fe82ecd1e65103/database/migrations/001_schema.sql#L73-L77)

### 2. Group image data

The helper reads image rows for all item IDs and groups them by ID. A detailed item read checks owner or admin before returning images. [listings.js 24–55](https://github.com/Abeerr0/mezyad/blob/e4fc24953b75d37f2f905df454fe82ecd1e65103/backend/src/listings.js#L24-L55) · [listings.js 282–295](https://github.com/Abeerr0/mezyad/blob/e4fc24953b75d37f2f905df454fe82ecd1e65103/backend/src/listings.js#L282-L295) · [app.js 997–1012](https://github.com/Abeerr0/mezyad/blob/e4fc24953b75d37f2f905df454fe82ecd1e65103/backend/src/app.js#L997-L1012)
