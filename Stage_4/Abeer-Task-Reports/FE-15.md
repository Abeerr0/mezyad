# Develop the home page and visual identity (FE-15)

**Status** Implemented

## Scope

The home page introduces Mezyad and helps a visitor choose where to go next. It brings together the brand imagery, active auctions, asset categories, a short overview of the journey and the private-auction entry.

## Implementation

### 1. Introduce the marketplace

The hero uses a branded image and two direct actions. Browse opens the catalog and selling goes through the shared action handler, which can send a visitor to sign-in first. The brand scene uses the current page to select the closing image and navigation link. [Home.jsx 20–76](https://github.com/Abeerr0/mezyad/blob/206b127eeb10af66ac115684d2531439a1405766/frontend/src/features/home/pages/Home/Home.jsx#L20-L76) · [App.jsx 207–227](https://github.com/Abeerr0/mezyad/blob/206b127eeb10af66ac115684d2531439a1405766/frontend/src/app/App.jsx#L207-L227) · [BrandScene.jsx 71–115](https://github.com/Abeerr0/mezyad/blob/206b127eeb10af66ac115684d2531439a1405766/frontend/src/shared/components/BrandScene.jsx#L71-L115)

### 2. Feature active public auctions

App loads categories and auctions together and keeps public auctions for the catalog. Home picks up to three active entries. Loading and request errors use the same state panel, while an empty active list explains that the visitor can see scheduled and finished auctions in Browse. [App.jsx 153–198](https://github.com/Abeerr0/mezyad/blob/206b127eeb10af66ac115684d2531439a1405766/frontend/src/app/App.jsx#L153-L198) · [Home.jsx 11–20](https://github.com/Abeerr0/mezyad/blob/206b127eeb10af66ac115684d2531439a1405766/frontend/src/features/home/pages/Home/Home.jsx#L11-L20) · [Home.jsx 91–122](https://github.com/Abeerr0/mezyad/blob/206b127eeb10af66ac115684d2531439a1405766/frontend/src/features/home/pages/Home/Home.jsx#L91-L122)

### 3. Guide visitors to a next step

Category links carry the selected category ID into Browse. The journey section introduces discovery, bidding and results, and offers the full guide. The private-auction entry gives invited visitors a route to the access form. [Home.jsx 155–175](https://github.com/Abeerr0/mezyad/blob/206b127eeb10af66ac115684d2531439a1405766/frontend/src/features/home/pages/Home/Home.jsx#L155-L175) · [Home.jsx 179–229](https://github.com/Abeerr0/mezyad/blob/206b127eeb10af66ac115684d2531439a1405766/frontend/src/features/home/pages/Home/Home.jsx#L179-L229) · [site-data.js 5–43](https://github.com/Abeerr0/mezyad/blob/206b127eeb10af66ac115684d2531439a1405766/frontend/src/shared/data/site-data.js#L5-L43)

## UI/UX

| Page or component | Frontend file | What the user sees and does |
| --- | --- | --- |
| Home hero | `Home.jsx` | See the Mezyad identity and choose between exploring auctions and listing an asset. |
| Featured auctions | `Home.jsx`, `AuctionCard.jsx`, `StatePanel.jsx` | Compare up to three active auctions. The section also explains when there are no active public auctions. |
